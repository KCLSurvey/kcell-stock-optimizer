===============================================================
  НАЧНИ ОТСЮДА
===============================================================

Терминал тебе не понадобится в привычном смысле — почти всё
делается мышкой. Читай сверху вниз и делай ровно то, что написано.

Права администратора НЕ нужны. Всё ставится в твою личную папку,
даже на корпоративном компьютере.


---------------------------------------------------------------
ШАГ 1. НАЙДИ РАСПАКОВАННУЮ ПАПКУ
---------------------------------------------------------------

Ты уже распаковал архив. Теперь надо найти получившуюся папку.

Скорее всего она лежит в "Загрузках":

  - Открой "Проводник" (жёлтая папка внизу экрана на панели задач)
  - Слева в списке найди "Загрузки" и щёлкни по ним
  - Найди папку с названием vision-navigator и открой её двойным щелчком

Ты должен увидеть внутри много файлов. Среди них будут:

  INSTALL
  START
  DIAGNOSTICS

ВАЖНО: Windows по умолчанию прячет окончания у названий файлов.
Поэтому ты увидишь просто "INSTALL", а не "1-INSTALL.bat".
Это нормально, так и должно быть.


---------------------------------------------------------------
ШАГ 2. ЗАПУСТИ УСТАНОВКУ
---------------------------------------------------------------

Щёлкни ДВА РАЗА по файлу с названием 1-INSTALL.bat


>>> ВНИМАНИЕ. СКОРЕЕ ВСЕГО ПОЯВИТСЯ СИНЕЕ ОКНО <<<

Оно будет называться:

    "Система Windows защитила ваш компьютер"

Это НЕ ошибка и НЕ вирус. Windows так реагирует на любой файл,
скачанный из интернета. Сделай так:

  1. Нажми маленькую надпись "Подробнее" (она слева внизу текста)
  2. Появится кнопка "Выполнить в любом случае" — нажми её

Всё, дальше пойдёт установка.


---------------------------------------------------------------
ШАГ 3. ВЫБЕРИ, ЧЕМ ПОЛЬЗОВАТЬСЯ
---------------------------------------------------------------

Откроется чёрное окно с белыми буквами. Это нормально, так и надо.
Ты увидишь список:

    1. Claude Code     - если платишь за Claude Pro или Max
    2. Codex           - если платишь за ChatGPT Plus или Pro
    3. Antigravity CLI - бесплатно, нужна только почта Gmail

Набери одну цифру и нажми Enter:

  - Платишь за Claude   -> набери  1
  - Платишь за ChatGPT  -> набери  2
  - Ни за что не платишь -> набери  3

Дальше программа спросит "Установить сейчас? [д/н]" — набери  д
и нажми Enter. Подожди минуту, идёт установка. Права администратора
она спрашивать не будет — их для этого способа не нужно.


---------------------------------------------------------------
ШАГ 4. ВХОД В СВОЙ АККАУНТ
---------------------------------------------------------------

В окне появится надпись:

    "Нажми Enter, когда будешь готов..."

Нажми клавишу Enter.

Откроется браузер. Там:

  - войди своей обычной почтой — той же, которой пользуешься
    на сайте Claude, ChatGPT или Google
  - если спросит разрешение — разреши
  - когда напишет, что всё получилось, закрой вкладку браузера

Когда увидишь надпись "ГОТОВО" в чёрном окне — закрой его.

Это делается один раз. Больше входить не придётся.


---------------------------------------------------------------
ШАГ 5. ЗАПУСК
---------------------------------------------------------------

Щёлкни два раза по файлу 2-START.bat

Откроется чёрное окно, и программа спросит, что делать:

    1. Пройти 6 методологий
    2. Собрать совет из 7 ролей
    3. Спросить у базы знаний
    4. Проверить базу знаний на противоречия
    5. Начать заново
    6. Сменить модель

Набери цифру и нажми Enter.

Для первого раза советую набрать  2  — это "совет". Он разберёт
твою идею с семи разных сторон и скажет, чего в ней не хватает.

Отвечать можно обычными словами, как будто говоришь с человеком.


ЕСЛИ ОТВЕТ ДЛИННЫЙ (несколько абзацев)
--------------------------------------

Не пиши длинный ответ прямо в чёрное окно — оно принимает только одну
строку и обрежет всё после первого переноса.

Вместо этого набери слово  файл  и нажми Enter. Откроется Блокнот:
пиши или вставляй туда сколько угодно текста, потом сохрани (Ctrl+S)
и просто закрой окно Блокнота. Программа сама всё прочитает и
продолжит. Ограничений по длине нет.


ЕСЛИ В БУФЕРЕ ОБМЕНА ПУСТО
--------------------------

Программа сохраняет текст запроса ещё и в файл ЗАПРОС.txt — он лежит
в папке твоей идеи (IDEAS\имя-идеи\). Открой его Блокнотом и скопируй
текст оттуда. Путь к файлу программа пишет на экране каждый раз.


Чтобы прерваться — напиши слово  exit  и нажми Enter.
Всё сохранится, потом продолжишь с того же места.


---------------------------------------------------------------
НЕ ПОЛУЧАЕТСЯ УСТАНОВИТЬ? (корпоративный firewall)
---------------------------------------------------------------

Если 1-INSTALL.bat пишет об ошибке сети или зависает — вероятно,
корпоративный firewall блокирует установку. Тогда есть режим,
который вообще ничего не устанавливает:

Щёлкни по START (не по 1-INSTALL.bat), и в меню выбери пункт

    0. Через браузер

Node.js, никакие программы — ничего не понадобится. На каждом
шаге программа сама скажет: "скопируй этот текст, вставь на сайте
claude.ai (или chatgpt.com), скопируй ответ сайта обратно, вставь
сюда". Медленнее (руками на каждый вопрос), зато работает всегда,
даже на самом закрытом компьютере.


---------------------------------------------------------------
ЕСЛИ ЧТО-ТО ЕЩЁ ПОШЛО НЕ ТАК
---------------------------------------------------------------

Щёлкни два раза по файлу DIAGNOSTICS.bat

Откроется окно, где будет написано, чего именно не хватает и что
с этим делать. Оно ничего не ломает и не устанавливает, только
смотрит.

Если непонятно — сфотографируй экран или скопируй текст из окна
и покажи тому, кто помогает.


ЧАСТЫЕ ВОПРОСЫ
--------------

"Окно открылось и сразу закрылось"
    Значит не хватает Python. Скачай с сайта python.org, поставь
    (в установщике отметь галочку "Add Python to PATH"), и запусти
    файл заново.

"Пишет, что не установлено, а я ставил приложение Claude"
    Приложение Claude с окном и кнопками — это другое. Нужна его
    версия для чёрного окна, она ставится отдельно, через файл
    INSTALL.

"Не могу найти файл 1-INSTALL.bat"
    Возможно ты в неправильной папке. Ищи ту, где рядом лежат
    файлы 2-START.bat и DIAGNOSTICS.bat.

"Установка не идёт, пишет что-то про сеть"
    Скорее всего корпоративный firewall. Используй режим
    "0. Через браузер" в файле 2-START.bat — он ничего не
    устанавливает и работает всегда.

"Не понимаю, за что я плачу — Claude или ChatGPT"
    Если не платишь ни за что — выбирай пункт 3 (Antigravity).
    Он бесплатный, нужна только почта Gmail.
