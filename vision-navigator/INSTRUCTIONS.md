# ИНСТРУКЦИЯ — с самого нуля

Написано для человека, который никогда не открывал «чёрное окно с текстом».
Ничего знать заранее не нужно. Делай ровно по шагам, сверху вниз.

Всё займёт минут двадцать. Один раз настроил — дальше запуск в одну команду.

---

## Что вообще происходит

У тебя есть смутная идея. Программа задаёт тебе вопросы по шести проверенным
методикам, помнит все твои ответы, ловит противоречия и возвращает назад, если
ты сам себе противоречишь. В конце собирает «совет» из семи ролей — инженер,
аудитор, инвестор и так далее — которые разбирают идею с разных сторон и
выносят вердикт.

Всё, что ты скажешь, копится в базе знаний, поэтому программа помнит разговоры
недельной давности.

---

## Шаг 1. Открыть терминал

Терминал — это окно, где вместо кнопок ты пишешь команды текстом.

**Windows:** нажми `Win` (кнопка с флажком) → напиши `powershell` → Enter.
Откроется синее или чёрное окно. Это он.

**Mac:** нажми `Cmd + пробел` → напиши `terminal` → Enter.

**Android:** установи приложение **Termux**. Лучше из магазина F-Droid, потому
что версия в Play Store давно не обновлялась.

**iPhone:** установи из App Store приложение **a-Shell** (бесплатное).

> Дальше везде, где написано «набери», — это значит: напечатай текст в этом
> окне и нажми Enter. Текст можно копировать и вставлять, набирать руками не
> обязательно. Вставка в Windows — правая кнопка мыши.

---

## Шаг 2. Проверить, есть ли Python

Программа написана на Python. Проверим, стоит ли он.

Набери:

```
python --version
```

**Если ответило что-то вроде `Python 3.12.1`** — отлично, иди к шагу 3.

**Если написало «не является внутренней или внешней командой»** или подобное —
Python нужно поставить:

- Зайди на **python.org**, раздел Downloads, скачай и запусти установщик.
- ⚠️ В первом окне установщика **обязательно поставь галочку «Add Python to
  PATH»** внизу. Без неё ничего не заработает, и это самая частая ошибка.
- После установки **закрой окно терминала и открой заново** — иначе он не
  увидит изменений.

На Mac Python обычно уже есть, но команда называется `python3`.
На Android в Termux набери `pkg install python`.

## Шаг 3. Подключить искусственный интеллект

С начала 2026 года это стало проще: Claude Code, Codex и Antigravity CLI
(замена Gemini CLI с июня 2026) ставятся **одной командой, без Node.js и
без прав администратора** — файл ставится прямо в твою личную папку.

**Проще всего вообще не делать этот шаг руками** — программа-установщик
(файл `INSTALL`, о нём в шаге 5) сама предложит поставить нужный
инструмент и сама откроет вход в аккаунт.

Если хочешь сделать заранее вручную — команды такие (обычный, НЕ "от
имени администратора" PowerShell):

**Claude** (нужна подписка Claude Pro или Max):
```
irm https://claude.ai/install.ps1 | iex
```
Затем `claude` — откроется вход в аккаунт через браузер.

**ChatGPT** (нужна подписка Plus или Pro):
```
irm https://chatgpt.com/codex/install.ps1 | iex
```
Затем `codex login`.

**Google, бесплатно** (нужна только почта Gmail):
```
irm https://antigravity.google/cli/install.ps1 | iex
```
Затем `agy` — откроется вход.

**Честное предупреждение.** У подписок есть суточные лимиты обращений.
Одно заседание совета — это тринадцать обращений. Если упрёшься в лимит,
программа не сломается: роль пометится ошибкой, остальные продолжат.

**Если корпоративный firewall блокирует установку** — не страшно, в
программе есть режим "Через браузер", который вообще ничего не
устанавливает (см. шаг 6).

## Шаг 4. Скачать саму программу

Распакуй архив, который я тебе дал, в удобное место. Например, на Windows —
в папку `C:\Users\<твоё имя>\vision-navigator`.

Теперь нужно «перейти» в эту папку в терминале. Набери `cd `, поставь пробел,
и **перетащи мышкой папку прямо в окно терминала** — путь подставится сам.
Потом Enter.

Выглядеть будет примерно так:

```
cd C:\Users\rassul\vision-navigator
```

Проверь, что попал куда надо — набери `dir` (Windows) или `ls` (всё остальное).
Должен увидеть файлы `start.py`, `README.md` и папки `docker`, `docs`.

## Шаг 5. Запустить — в одно нажатие

**Windows:** просто **два раза щёлкни по файлу `Запустить-Windows.bat`**.
Ничего набирать не нужно. Если Python не установлен, он сам откроет сайт
и подскажет, что делать.

**Mac:** два раза щёлкни по `Запустить-Mac.command`. Если Mac скажет
«неизвестный разработчик» — щёлкни правой кнопкой и выбери «Открыть».

**Android — значок на рабочем столе, одно нажатие:**

```
bash установить-на-телефон.sh
```

Скрипт сам поставит Python и Node.js и создаст ярлык. Дальше два действия
руками: установи приложение **Termux:Widget** (там же, где Termux — в F-Droid),
затем на рабочем столе телефона задержи палец на пустом месте → «Виджеты» →
найди Termux:Widget → перетащи на экран → выбери «Навигатор».
Всё, дальше программа открывается одним нажатием по значку.

**Если хочется вручную (любая система):**

```
python start.py
```

При первом запуске программа спросит, какую модель использовать. Увидишь
список, где напротив каждой написано, установлена она или нет. Выбирай ту, где
написано «установлен», — номер и Enter.

Дальше появится меню:

```
0. Через браузер - копировать/вставлять руками (если ничего не установилось)
1. Пройти 6 методологий (начать или продолжить)
2. Собрать совет из 7 ролей и получить вердикт
3. Спросить у базы знаний
4. Проверить базу знаний на противоречия
5. Начать текущую идею заново
6. Сменить модель
```

Нажми `1`, придумай короткое имя идее (например, `telecom`) — и начнётся
разговор. Отвечай развёрнуто, обычным текстом, как живому человеку.

**Важно:** можно в любой момент написать `exit` и выйти. Всё сохранится.
Вернёшься завтра — продолжит с того же места.

## Шаг 6. Как этим пользоваться по-настоящему

Правильный порядок работы:

1. **Сразу собери совет (пункт 2), не проходя методологии.** Звучит странно, но
   именно на сыром материале скептики — критик и инвестор — вскрывают то, чего
   не хватает. Терять ещё нечего.
2. **Пройди шесть методологий (пункт 1).** Не за один присест. Это несколько
   вечеров, и это нормально — тут важно думать, а не быстро прокликать.
3. **Собери совет второй раз.** Теперь по готовому видению. Он увидит, что
   изменилось, потому что помнит первое заседание.
4. **Вопросы из вердикта верни в разговор.** Совет в конце выдаёт список
   открытых вопросов — это и есть материал для следующего круга.
5. **Иногда жми пункт 4** — проверку базы знаний. Она найдёт места, где ты сам
   себе противоречишь, и где догадка незаметно превратилась в «факт».

Повторяй, пока вердикт не станет `proceed`.

## Шаг 7 (необязательный). Граф связей

Есть отдельная программа **graphify**, которая строит карту связей между всем,
что ты наговорил: какие темы связаны, что с чем пересекается, что оказалось в
центре. Программа сама её подхватит, если она установлена.

```
pip install graphifyy
```

Не установишь — ничего не сломается, просто карты связей не будет.

## Если что-то не находится — сначала диагностика

```
файл DIAGNOSTICS (двойной щелчок)
```

Она ничего не устанавливает и не ломает — только смотрит и объясняет, чего
именно не хватает и что с этим делать. Если программа пишет «не установлено»,
а ты уверен, что ставил — запускай в первую очередь её.

### Частая путаница: приложение и терминальная версия — разные вещи

| Что это | Как выглядит | Подходит? |
|---|---|---|
| Приложение Claude / ChatGPT | Окно с кнопками, как обычная программа | **Нет** |
| Claude Code / Codex CLI | Работает только в терминале, окна нет | **Да** |

Это отдельные установки. Наличие первого не даёт второго. Ставится так:

```
irm https://claude.ai/install.ps1 | iex               (для подписки Claude Pro/Max)
irm https://chatgpt.com/codex/install.ps1 | iex        (для подписки ChatGPT Plus/Pro)
irm https://antigravity.google/cli/install.ps1 | iex   (для Google, бесплатно)
```

Ни одна из этих команд не требует Node.js и не требует прав администратора —
файл ставится прямо в твою личную папку.

### Вторая частая причина: Windows не видит только что установленное

После установки папка с программой попадает в список известных Windows
**только в новых окнах терминала**. Поэтому: закрой окно, открой заново,
попробуй снова. Это лечит большинство случаев «я же поставил, а оно не видит».

## Если что-то пошло не так

**«python не является внутренней или внешней командой»**
Python не установлен или при установке забыта галочка «Add Python to PATH».
Переустанови с галочкой и перезапусти терминал.

**«Программа не установлена», хотя ты её ставил**
Запусти `файл DIAGNOSTICS (двойной щелчок)` — она скажет точно. Скорее всего либо стоит
приложение с окном вместо терминальной версии, либо терминал не перезапущен
после установки.

**«Программа claude установлена, но вход в аккаунт не выполнен»**
Именно то, что написано. Набери в терминале `claude` (или `codex login`, или
`gemini` — смотря что выбрал), войди своей обычной почтой в браузере, вернись
и запусти программу снова. Твой ответ при этом не потерялся.

**«Не найдена программа "claude"»**
Не выполнен шаг 3, или терминал не перезапущен после установки. Закрой окно,
открой заново, попробуй снова.

**Программа пишет про лимиты или ошибку 429**
Упёрся в суточный лимит подписки. Подожди несколько часов либо переключись на
другую модель через пункт 6 меню.

**Ответ приходит странный, не по делу**
Проверь, что вошёл в аккаунт: набери `claude` (или `codex login status`) и
посмотри, не просит ли программа авторизацию заново.

**Всё запуталось, хочу начать заново**
Пункт 5 в меню стирает текущую идею. Прогресс других идей не тронет.

## Где что лежит

Всё, что программа делает, складывается в папку `IDEAS/<имя-идеи>/`:

```
raw/          твои исходные ответы, никогда не изменяются
wiki/         страницы знаний, которые модель пишет и обновляет сама
council/      мнения ролей и вердикт
logs/         история: что когда произошло и почему вернули назад
vision.md     итоговое видение
task.md       техзадание, если дальше пойдёт разработка
```

Всё это обычные текстовые файлы. Их можно открыть Блокнотом и прочитать.
Никакой базы данных, ничего не спрятано.
