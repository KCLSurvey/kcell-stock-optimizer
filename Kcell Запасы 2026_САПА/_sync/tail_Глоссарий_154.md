## Финансовые понятия

| Термин | Значение |
|---|---|
| **TAM / SAM / SOM** | Общий / доступный / реалистично захватываемый объём рынка |
| **ARR / MRR** | Годовая / месячная повторяющаяся выручка |
| **CAC** | Стоимость привлечения клиента |
| **LTV** | Пожизненная ценность клиента |
| **Churn** | Отток клиентов |
| **Carrying cost** | Стоимость хранения запаса: капитал, склад, страховка, устаревание |
| **Success fee** | Вознаграждение как доля от достигнутого эффекта |
| **Beachhead** | Плацдарм — первый узкий сегмент для выхода на рынок |
