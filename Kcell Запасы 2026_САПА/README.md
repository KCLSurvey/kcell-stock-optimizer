# Kcell Запасы 2026_САПА

Рабочая папка для ведения графа знаний и вики проекта «Kcell Запасы 2026» (САПА).

## Структура

- `wiki/` — страницы вики Корпатого (Markdown, по разделам)
- `graphify-out/` — граф знаний, построенный скиллом graphify (god nodes, community detection, поисковые индексы)

## Как обновлять

- Изменения в вики вносятся напрямую в `wiki/*.md`
- Граф знаний перестраивается/дополняется вызовом скилла `graphify` над содержимым `wiki/` и остальными материалами проекта
- Работа ведётся в этом репозитории, ветка `claude/knowledge-folder-sync-e12nli`; синхронизация с локальным компьютером — через `git pull`
